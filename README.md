# Logistics News: GDELT → Russian JSON → DataLens

Бесплатная ежедневная лента значимых новостей грузовой логистики.

Что делает проект:

- получает публикации за последние 24 часа из бесплатного GDELT DOC API;
- отслеживает авто, железную дорогу, море и авиагруз;
- повышает приоритет событий по Беларуси, России, Турции и Китаю;
- переводит англоязычные публикации на русский локально через Argos Translate;
- формирует обязательные поля «Причина» и «Последствие» по прозрачным правилам;
- сохраняет до 12 карточек в `news.json`;
- обновляется ежедневно и может запускаться вручную.

Платёжный аккаунт, банковская карта и API-ключи не требуются.

## Первый запуск на GitHub

1. Создайте **публичный** репозиторий с точным именем `logistics-news-gdelt`.
2. Загрузите в корень репозитория всё содержимое этой папки, включая папку
   `.github`.
3. Откройте **Settings → Actions → General**.
4. В разделе **Workflow permissions** выберите **Read and write permissions** и
   нажмите **Save**.
5. Откройте **Actions → Update logistics news**.
6. Нажмите **Run workflow → Run workflow**.
7. Первый запуск может занять несколько минут: загружается бесплатная модель
   перевода. Дождитесь зелёной отметки.
8. Откройте `news.json` и проверьте, что массив `news` заполнен.

Дальнейшая настройка DataLens описана в `DATALENS_SETUP.md`.

## Файлы

- `update_news.py` — загрузка, фильтрация, перевод и правила оценки.
- `requirements.txt` — бесплатные библиотеки Python.
- `.github/workflows/update-news.yml` — ежедневный и ручной запуск.
- `news.json` — готовый источник для DataLens.
- `datalens/` — код вкладок Advanced-чарта.

## Безопасность расходов

Проект не вызывает платные AI API и не содержит ключей. Для публичного
репозитория стандартные GitHub-hosted Actions бесплатны. Если GitHub изменит
лимиты или заблокирует выполнение, деньги автоматически не списываются без
настроенного платёжного способа и бюджета.
