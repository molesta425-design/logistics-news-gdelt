# Подключение бесплатной ленты к DataLens

Эти шаги выполняются после первого успешного запуска GitHub Actions.

## 1. Проверьте публичную ссылку

Замените `GITHUB_LOGIN` своим логином и откройте:

`https://raw.githubusercontent.com/GITHUB_LOGIN/logistics-news-gdelt/main/news.json`

В браузере должен открыться JSON с полями `updatedAt` и `news`.

## 2. Создайте API Connector

В том же воркбуке DataLens выберите **Создать → Подключение → API Connector**.

- Имя хоста: `raw.githubusercontent.com`
- Порт: `443`
- URL-путь: `GITHUB_LOGIN/logistics-news-gdelt/main/`
- HTTPS: включить
- Разрешённый метод: `GET`
- Заголовки: не добавлять
- Название: `GitHub Logistics News`

Сохраните подключение и скопируйте его ID.

## 3. Измените Advanced-чарт

### Meta

Полностью замените содержимое кодом из `datalens/meta.json` и вместо
`PASTE_API_CONNECTOR_ID_HERE` вставьте ID нового подключения.

### Params

Полностью замените содержимое кодом из `datalens/params.js`.

### Sources

Полностью замените содержимое кодом из `datalens/sources.js`.

### Controls

Полностью замените содержимое кодом из `datalens/controls.js`.

### Prepare

В текущем коде Prepare найдите первую строку:

`const loaded = Editor.getLoadedData();`

Удалите код от неё до первой строки:

`Editor.setRawData(news);`

включительно. На его место вставьте весь код из
`datalens/prepare-loader.js`. Остальную часть Prepare, начиная с
`module.exports = {`, не меняйте.

### Config

Оставьте вкладку пустой.

Нажмите **Выполнить**, затем сохраните чарт.

## Как работает обновление

- GitHub формирует новый `news.json` ежедневно примерно в 08:20 по Минску/Москве.
- Кнопка **Обновить новости** в DataLens повторно загружает последний файл.
- Кнопка не запускает GitHub раньше расписания.
- При сбое GDELT старый успешный файл сохраняется, поэтому виджет не становится пустым.

## Важное ограничение

Перевод выполняет локальная открытая модель. Причина и последствие формируются
по типу события и ключевым словам. Это бесплатная алгоритмическая оценка, а не
проверенный AI-анализ. Для решений по конкретной перевозке откройте ссылку на
источник в карточке.
